# DNS Tunneling Detection System

## Overview

We developed this real-time, flow-based machine learning tool for
detecting DNS tunneling.

Instead of relying on signatures or domain blacklists, We designed the system to analyze
behavioral and statistical characteristics of DNS traffic.

A Python tool called **dnssniffer** uses Scapy to capture DNS packets,
aggregates them into bidirectional flows, extracts **31 features**, and
classifies each flow as either **Benign** or **DNS Tunnel**.

## The Challenge

> How can We detect DNS tunneling reliably from network behavior rather
> than relying on signatures or domain blacklists, while maintaining the
> ability to analyze traffic in real time?

## Methodology

1. **We captured** DNS traffic from the network in real time and grouped related packets into flows.

2. **We extracted** 31 features from each DNS flow, including domain, traffic, packet size, timing, and statistical characteristics.

3. **We preprocessed and normalized** the data using transformations and feature scaling to prepare it for machine learning.

4. **We built and trained** a Random Forest model using benign and malicious DNS traffic from the DNS-Tunnel-Dataset.

5. **We detected** suspicious DNS flows by identifying patterns that differ from normal DNS communication and may indicate tunneling.

6. **We analyzed** DNS tunneling behavior by testing traffic generated by tools such as iodine, dnscat2, and dns2tcp.

7. **We implemented** near real-time detection by analyzing flows as packets were collected, providing a balance between detection speed and accuracy.

8. **We evaluated** the model using Precision, Recall, and F1-Score, with initial testing achieving an F1-score above 0.95 on unencrypted DNS traffic.

9. **We identified** limitations of the approach, particularly with encrypted DNS protocols such as DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT).

10. **We packaged and published** `dnssniffer` on PyPI, turning the project into a reusable Python tool for DNS traffic analysis and tunneling detection.
