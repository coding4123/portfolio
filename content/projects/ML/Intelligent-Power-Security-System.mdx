# Intelligent Power & Security System

## Overview

Server rooms and call centers depend on stable environmental conditions and controlled physical access. Temperature increases, smoke, water leaks, or unauthorized entry can quickly become critical problems.

Our solution combines **environmental monitoring, intelligent cooling, anomaly detection, and access control** into one connected system.

The prototype collects real-time sensor data through microcontrollers, communicates through MQTT, applies intelligent control and detection logic, and presents the system state through a web dashboard.

## The Challenge

> How can we make critical technical spaces safer and more responsive to environmental hazards and unauthorized access?

Traditional monitoring systems can detect individual problems, but they may rely on simple thresholds or isolated components.

We wanted to explore a system that could **continuously monitor its environment, react automatically, and provide operators with a unified view of what is happening**.

The main constraint was time: the entire prototype had to be developed during **three consecutive nights of a hackathon**.

## Methodology

1. **We identified** the main environmental and security risks in critical technical spaces.
2. **We defined** the sensors, actuators, and access-control mechanisms required.
3. **We connected** the hardware components through ESP32 and Arduino microcontrollers.
4. **We collected** environmental and security data in real time.
5. **We transmitted** sensor readings and events through MQTT.
6. **We processed** incoming data using control and detection logic.
7. **We adapted** fan speed according to environmental conditions.
8. **We detected** abnormal events such as overheating, intrusion, and water leakage.
9. **We authenticated** access using RFID and facial recognition.
10. **We visualized** system states, alerts, and logs through the web dashboard.
11. **We integrated** the individual components into a unified prototype.
12. **We tested** the system under the constraints of the three-night hackathon.
