# Booky Trans - Website Development

## Overview

Booky Trans was created to address the language barrier that prevents many readers from accessing books written in other languages.

Instead of limiting readers to the original language of a book, the platform provides a space where books can be translated and made available to a wider audience.

We brought book discovery, translation, and reading together in one experience.

## The Challenge

> How can we make books written in different languages easier for readers to discover and understand?

Many valuable books are only available in a limited number of languages. Readers who do not understand the original language may have difficulty accessing the content or finding a suitable translation.

The challenge was to create a platform that makes translated books easy to discover while keeping the reading experience simple and accessible.

## Methodology

1. **We identified** user needs by understanding how readers discover books and deal with language barriers.
2. **We defined** the user flow from discovering a book to selecting a language, translating the content, and reading it.
3. **We designed** the interface in Figma, focusing on clear navigation, readable layouts, and an accessible reading experience.
4. **We developed** the website using HTML, CSS, and JavaScript to implement the main pages and interactions.
5. **We tested and refined** the experience by reviewing navigation, readability, responsiveness, and the overall usability of the platform.
